// CORE TECHNOLOGY

四大核心技术

区块链不是单一技术，而是密码学、分布式系统、博弈论的综合应用

🔗

链式数据结构

每个区块包含前一个区块的哈希，形成不可篡改的链条。修改任何一个区块都会导致后续所有区块的哈希失效。

查看区块浏览器 →
#️⃣

密码学哈希

SHA-256 与国密 SM3 双哈希算法，将任意长度的数据映射为固定长度的"数字指纹"，具有单向性和抗碰撞性。

进入哈希实验室 →
🤝

分布式共识

PBFT 拜占庭容错共识算法，在不可信网络中让多个节点就数据状态达成一致，最多容忍 (n-1)/3 个恶意节点。

观看共识演示 →
📜

智能合约

运行在区块链上的自动化代码，一旦部署不可篡改，按照预设逻辑自动执行，确保结果可验证、可追溯。

查看存证合约 →
🔐

数字签名

基于椭圆曲线的非对称加密，用私钥签名、公钥验签，确保数据的身份认证和不可否认性。

了解签名机制 →
🌐

国密合规

原生支持 SM2 签名、SM3 哈希、SM4 加密三大国密算法，符合国内密码管理政策和等保要求。
