三阶段共识 // THREE-PHASE
PBFT 核心流程
📢

预准备 Pre-Prepare

主节点（Leader）收到客户端请求后，将请求编号并广播给所有从节点，告诉大家"我们来处理这个请求"。

主节点分配序号，全网统一排序
✅

准备 Prepare

从节点收到预准备消息后，验证通过就向所有节点广播 Prepare 消息。当节点收到 2f 个 Prepare 消息，进入准备状态。

收到 2f+1 个一致消息 = 达成准备
📝

提交 Commit

节点进入准备状态后，广播 Commit 消息。当收到 2f+1 个 Commit 消息，就可以提交请求并执行操作。

收到 2f+1 个 Commit = 最终确认
